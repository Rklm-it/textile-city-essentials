# Ветка `deploy` — собранный прототип «Текстиль-Сити»

**Генерируется, руками не правится.** Ветку перезаписывает принудительный пуш
из сессии; в `main` она не сливается — `main` синхронизирован с Lovable.

Здесь лежит результат сборки, а не исходники: готовая разметка `index.html`
(30 КБ со всем текстом — не пустая оболочка), клиентский бандл `assets/`,
фотографии `images/` и превью `og.png`.

Почему так: VPS прототипов — 961 МБ памяти, `bun run build` там получает
SIGKILL от OOM-killer. Поэтому проект собирается вне сервера, а на сервер
уезжает готовое. Рантайма не нужно: страница статическая, отдаёт её Caddy.

Выкладка — на **сервере прототипов**:

```bash
cd /root/site-scanner/deploy/prototype
./sync.sh textileopt https://github.com/Rklm-it/textile-city-essentials.git
```

Проверено перед сборкой: интерактив работает без сервера (ползунок ширины
считает, форма отвечает), следов конструктора нет, `tsc` и `eslint` чисты.
